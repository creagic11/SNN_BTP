# Project notes

Working documents of the project. They record how the work was planned and carried out and serve as study
material. The technical content of the project is in the paper (`paper/`), the technical notes (`docs/`) and the
result reports (`results/`).

| File | Content |
| --- | --- |
| `proposal_v2.md` | Project proposal (15 October 2026): problem, formulation, safety theorem, plan |
| `plan_tier1.md` | Research plan of 26–27 October 2026 and the decisions taken on it |
| `plan_nov2026.md` | Execution plan for the paper (3–11 November 2026) with task status |
| `paper_outline.md` | Outline of the paper, its claims and the source of every figure and table |
| `development_log.md` | Dated record of every task, result, correction and decision |
| `primer.md` | Self-contained explanation of the whole project with the current numbers |
| `study_checklist.md` | Self-assessment checklist covering the theory, hardware, results and anticipated questions |

Numbers in the plans and in older log entries reflect the state at the time of writing. The current numbers are
those in the paper, `README.md` and `results/`.
