# Results

All numbers reported in the paper are taken from files in this directory. Accuracies use the hardware's integer
decision rule (most output spikes; ties broken by the larger summed membrane potential, then the lower class index)
on the full 10,000-sample N-MNIST test set.

## Trained networks

Each run directory holds `weights.npz` (INT8 weights and neuron parameters), `metrics.json` (per-epoch training
record) and, where measured, `net_perf.json` (whole-network latency and reads from the cycle model), `rtl_perf.json`
(hidden-layer cycle model) and `rho.json` (sleep statistics). The training log of a run `<tag>` is
`logs/train_<tag>.log`. Seeds 1 and 2 carry the suffixes `_s1` and `_s2`; no suffix denotes seed 0.

| Directory | Network |
| --- | --- |
| `nmnist_T100` | Ungated 578-256-10 network, 10 epochs (starting point of all gated networks; weights used for Spiker+) |
| `nmnist_T100_ft12_ctrl` | BASE of the paper: the 10-epoch network trained for 12 further epochs without the gate (98.21 %) |
| `nmnist_T100_mf_e025_d01_ep12` | HUSH gentler: mean-field gate, λ_e = 0.25, λ_d = 0.1, 12 fine-tuning epochs |
| `nmnist_T100_mf_e05_d025_ep12` | HUSH gentle: λ_e = 0.5, λ_d = 0.25, 12 fine-tuning epochs |
| `nmnist_T100_mf_e2_d1` | HUSH aggressive: λ_e = 2, λ_d = 1, 6 fine-tuning epochs |
| `nmnist_T100_mf_e05_d025` | Gentle setting with 6 fine-tuning epochs (superseded by the 12-epoch network) |
| `nmnist_T100_mf_e025_d01`, `nmnist_T100_mf_e0.1_d0`, `nmnist_T100_mf_e0.25_d0` | Single-seed exploration of the penalty weights |
| `nmnist_T100_h384`, `nmnist_T100_h384_mf_e05_d025` | Wider hidden layer (384 neurons), ungated and gated |
| `shd_*` | Spiking Heidelberg Digits study: feed-forward (`shd_T250*`), recurrent adaptive LIF (`shd_rec*`) and axonal-delay (`shd_delay*`) networks; see `regime_study.md` and `docs/headroom_model.md` |
| `mnist_400` | Rate-coded MNIST 784-400-10 network of the feasibility study; see `rho_unclustered.md` |

## Reports

| File | Content |
| --- | --- |
| `net_latency.md` | Whole-network latency per inference, three seeds × 500 test samples |
| `acc_integer.json` | Test accuracy of every network with the integer decision rule |
| `resources.md` | Per-module resources of the two power builds and the two stream builds |

| `heuristic_gates.md` | HUSH against heuristic predictors on the same networks |

| `realtime/` | Stream statistics, sensor-timing replay, replay-speed sweep, accuracy against elapsed time |
| `net/` | Bit-exact whole-network simulations (four networks × 50 samples) and the 80-case randomised regression |
| `spikerplus/` | Spiker+ accuracy on our weights and its GHDL simulation of 20 samples |
| `G0_report.md` | Feasibility study and the decision to focus on event-driven workloads |
| `regime_study.md` | Spiking Heidelberg Digits study: where hibernation pays |
| `rho_unclustered.md` | Rate-coded MNIST: sleep fraction before and after neuron clustering |
| `synth_yosys.md` | Early resource estimate with open-source synthesis (superseded) |
| `logs/` | Training and sweep logs |
| `archive/` | Superseded hardware runs and exploratory ablations; see `archive/README.md` |
